# SkillLoop project resources

Public project page: https://comp5241project.github.io/SkillLoop/

Four homepage entries:
- Public GitHub repository: https://github.com/comp5241project/SkillLoop
- Deployed app: https://skillloop-sigma.vercel.app/
- Overview video (5 minutes 59 seconds)

The video and both PDFs are stored in `assets/submissions/` and linked in `resources` in `script.js`. The video opens in a player; the report and slides open as PDFs. Set `accessNote` to the verified app login instructions. Never publish a personal account password or an API key.

The published source is the root of `gh-pages`. Changes to this page do not require changing application code or merging `main`.

Use relative asset paths. This page has no libraries, build step or external fonts.
