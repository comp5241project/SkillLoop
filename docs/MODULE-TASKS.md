# Starting tasks

These are suggested tasks for the four module owners. They can be copied into GitHub issues and adjusted after user feedback.

## Knowledge map

Expand the sample topic map and short lessons, improve the prerequisite relationships, and add useful practice entry points. Keep topic IDs stable. Completion for this task means a student can select a topic, read its lesson, follow a practice link and return without losing the local study record.

## Personalised paths

Expand the initial assessment beyond one question and explain why a lesson is recommended. Test with classmates at different starting points. Completion means the assessment can distinguish relevant knowledge gaps and every recommended lesson link opens the correct topic.

## Mock interview and process review

Add more reviewed interview questions and useful follow-ups. Make answers, revisions and hints easy to review. Completion means a complete practice session can be reviewed after a refresh. Real AI feedback should be added through an agreed backend, with preset examples still available for testing.

## Correction lab

Add reviewed code and workflow cases, clear acceptance criteria and follow-up exercises. Completion means a student can identify a problem, explain a fix, compare it against evidence or checks, and attempt a related task. Do not describe the current preset explanation as automatic grading.

## Shared tasks

Agree the common data contracts, keep navigation and styling consistent, test cross-module flows, and maintain deployment instructions. Account and instructor features are later shared work, not implemented in this starter.
