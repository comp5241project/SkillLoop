# SkillLoop

## Language

**Course**
A teacher-owned instructional offering. A course can use a software engineering case to give learners a problem to investigate.

**Course Unit**
The instructional material a learner works through, including objectives, explanations, code activities, exercises and optional hints.

**Case Definition**
A versioned software engineering problem with canonical public facts and separate private evaluation criteria.

**Case Binding**
An optional reference from a course unit to a particular case version and teaching concept.

**Published Course Version**
A fixed release of reviewed learner-facing course material with its case binding at publication time.

**Learner Activity**
An observed interaction with a published course version. A practice submission records participation without asserting correctness or mastery.
